# Afterglow Beam

An original landing-page demo: a single warm beam of light, driven by scrolling.

- Deep dusk background with a warm horizon glow, in the spirit of a sunset afterglow
- One golden beam loops as you scroll: it falls from top to bottom, sweeps left
  to right, comes back right to left, then loops again — one full loop per
  stretch of scrolling, for as long as you keep going
- Canvas-based, no libraries, no build step; the beam glides with smoothed
  scroll tracking, a fading trail, a white-hot core and drifting dust motes

## Run it

Just open `index.html` in a browser and scroll. Or visit the GitHub Pages site.

## Notes

All code, layout and copy here are original work written for this demo. It takes
visual inspiration from the warm sunset-glow look, and does not reproduce any
