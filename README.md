# Flowline

An original landing-page concept demo: a pure black page with a fine dot grid
and a single liquid light stream that flows from the top of the page to the
bottom as you scroll.

- Bright electric-lime core fading to cyan, with a soft volumetric glow
- Thin diagonal filaments at the top, swelling into a twisting stream
  mid-page, opening into diagonal mist bands, then dissolving into a pale
  glow at the bottom
- Canvas-based animation driven by scroll position — no libraries, no build step

## Run it

Just open `index.html` in a browser and scroll.

## Notes

All copy, layout and code here are original work written for this demo. It is
inspired by the general idea of a dark page with a flowing light stream, and
does not reproduce any third-party template, text or assets.
